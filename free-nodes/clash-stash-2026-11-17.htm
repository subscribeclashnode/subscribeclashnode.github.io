二、Quantumult的基本功能概览

在正式进入安装与配置教程之前，我们有必要先了解一下Quantumult的核心功能。只有理解了它能做什么，我们才能更好地利用它来满足自己的需求。

广告过滤（AD Filtering）

这是Quantumult最受欢迎的功能之一。通过内置的广告过滤规则，它可以有效阻止网页和应用程序中的广告展示，让你的浏览体验更加清爽。不仅如此，广告过滤还能减少不必要的流量消耗，提升页面加载速度。

代理配置（Proxy Configuration）

Quantumult支持HTTP、HTTPS、SOCKS5等多种代理协议，用户可以根据自己的实际需求选择合适的代理方式。无论你是需要访问特定地区的服务，还是希望提升网络连接的安全性，Quantumult都能提供灵活的代理配置选项。

规则管理（Rule Management）

这是Quantumult最强大的功能之一。通过自定义规则，用户可以精确控制哪些流量走代理、哪些流量直连、哪些流量被拒绝。这种精细化的管理方式，使得用户可以根据不同的使用场景，灵活调整网络策略。

网络速度测试（Speed Test）

Quantumult内置了网络速度测试功能，帮助用户快速评估不同代理节点的性能，从而选择最佳的代理服务器。这对于需要频繁切换代理的用户来说，是一个非常实用的功能。

三、Quantumult应用的下载和安装

安装Quantumult的过程并不复杂，但需要注意一些细节。以下是详细的步骤：

第一步：打开App Store

在你的iOS设备上找到并打开App Store应用。确保你的设备已经登录了Apple ID，并且网络连接正常。

第二步：搜索Quantumult

在App Store的搜索框中输入“Quantumult”，然后点击搜索按钮。你会看到相关的应用列表。

第三步：下载并安装

找到Quantumult应用后，点击“获取”按钮进行下载与安装。需要注意的是，Quantumult是一款付费应用，你可能需要支付一定的费用才能完成下载。此外，由于某些地区的App Store可能无法搜索到该应用，你可能需要切换到其他地区的Apple ID才能找到它。

第四步：确认安装完成

安装完成后，你可以在设备的主屏幕上找到Quantumult的图标。点击图标进入应用，开始进行后续的设置。

值得一提的是，Quantumult目前已经发展出了多个版本，包括Quantumult X等。不同版本在功能和界面上可能有所差异，但核心的策略配置逻辑是相通的。本文主要以Quantumult为基础进行讲解，其他版本的配置思路也可以参考。

四、Quantumult的基础设置

打开Quantumult应用后，你会看到一个相对简洁的初始设置界面。虽然界面看起来不复杂，但其中涉及的设置项却非常关键。以下是你需要进行的基础设置：

允许VPN连接

Quantumult作为一款网络代理工具，需要获得VPN连接的权限才能正常工作。在首次打开应用时，系统会提示你授权Quantumult使用虚拟专用网络。请务必点击“允许”，否则应用将无法正常代理你的网络流量。

如果你不小心拒绝了授权，可以前往iOS设备的“设置”>“通用”>“VPN与设备管理”中重新进行授权。

导入自定义配置

Quantumult支持通过QR码或相关链接导入他人的配置文件。这对于新手用户来说非常方便，因为你可以直接使用别人已经优化好的配置，而无需从零开始手动设置。通常，你可以在一些技术论坛或社区中找到共享的配置文件链接。

导入配置的方法很简单：在Quantumult的主界面中找到“导入”选项，然后扫描QR码或粘贴配置链接即可。导入完成后，应用会自动应用这些配置。

手动设置代理

如果你了解自己的代理服务器信息，也可以选择手动添加代理。在Quantumult的代理设置界面中，点击“添加”按钮，然后填写代理服务器的地址、端口、协议类型以及认证信息等。手动设置虽然相对繁琐，但能够让你完全掌控代理的每一个细节。

完成以上基础设置后，你就可以开始配置具体的策略了。接下来，我们将深入讲解Quantumult策略的配置方法。

五、Quantumult策略的配置详解

策略配置是Quantumult最核心、也是最灵活的部分。通过合理配置策略，你可以实现流量的精细化管理，从而在不同场景下获得最佳的网络体验。

5.1 创建新策略

在Quantumult中创建新策略的步骤如下：

首先，进入“策略”界面。你通常可以在底部导航栏或侧边菜单中找到这个选项。进入策略界面后，点击右上角的“添加”按钮，开始创建新策略。

在创建策略时，你需要配置以下几个关键参数：

  • 策略名称：为你的策略起一个易于识别的名称，比如“直连”、“代理”、“广告拦截”等。
  • 关联规则：选择该策略所关联的规则。规则决定了哪些流量会应用这个策略。
  • 具体参数：根据你选择的策略类型，填写相应的参数，比如代理服务器地址、端口等。

5.2 常见规则类型

在Quantumult中，最常见的规则类型包括以下三种：

DIRECT（直接连接）

DIRECT表示不使用代理，直接访问互联网。这种规则通常用于访问国内网站或不需要代理的服务。通过将特定流量设置为DIRECT，你可以避免不必要的代理开销，提升访问速度。

PROXY（代理连接）

PROXY表示使用设置的代理来访问目标地址。这种规则适用于需要翻墙访问的网站或服务。你可以为不同的代理服务器创建不同的PROXY策略，以便根据需求灵活切换。

REJECT（拒绝访问）

REJECT表示拒绝访问某个特定地址。这种规则通常用于拦截广告、追踪器或其他不需要的流量。通过将广告域名设置为REJECT，你可以有效阻止广告的加载，提升浏览体验。

5.3 优先级管理

在实际使用中，你可能会创建多个策略，而这些策略之间可能存在冲突。为了确保Quantumult按照你的预期工作，你需要合理管理策略的优先级。

Quantumult通常按照规则列表的顺序从上到下进行匹配，一旦匹配到某条规则，就会应用相应的策略并停止继续匹配。因此，你需要将最重要、最具体的规则放在前面，将通用规则放在后面。

例如，你可以将广告拦截规则放在最前面，确保广告流量被优先拦截；然后将需要代理的规则放在中间；最后将默认规则设置为DIRECT，处理所有未被匹配的流量。

5.4 策略分组与负载均衡

对于高级用户来说，Quantumult还支持策略分组和负载均衡功能。你可以将多个代理服务器归入同一个策略组，然后设置负载均衡模式，让Quantumult自动选择延迟最低或负载最轻的服务器。这对于需要稳定高速连接的用户来说，非常实用。

六、如何使用Quantumult策略

配置完成后，你需要通过实际使用来验证策略的效果。以下是一些建议的使用方法：

测试网络速度

在Quantumult中，你可以使用内置的速度测试功能，评估不同代理节点的性能。通过对比不同节点的延迟和速度，你可以选择最适合当前网络环境的代理。

访问不同网站

尝试访问不同类型的网站，观察策略是否按照预期工作。比如，访问国内网站时应该走DIRECT，访问国外网站时应该走PROXY，而广告域名应该被REJECT。

观察流量使用情况

Quantumult提供了流量统计功能，你可以通过它跟踪数据使用情况，了解哪些应用或网站消耗了最多的流量。这对于优化策略和节省流量非常有帮助。

定期更新规则

网络环境是不断变化的，广告域名和代理需求也会随之变化。因此，建议你定期更新Quantumult的规则和配置，以确保策略始终有效。

WebSocket 通过 HTTP 封装 TCP 流量，适合伪装成正常网页请求，增加隐蔽性。相比原生 TCP，可更好地绕过封锁和 DPI 检测，但略增加协议开销。
Mellow TUN 模式适合哪些应用？
TUN 模式拦截系统 IP 层流量，实现全局代理。适合游戏、视频、浏览器等全局应用，保证所有流量走节点，提高网络稳定性和速度，比普通 SOCKS5 代理覆盖范围更广。
SSR 的混淆方式如何选择最合适？
根据网络环境选择适合的混淆方式，如 tls1.2_ticket_auth 模拟 HTTPS 流量，可隐藏真实特征。结合协议插件使用，可以提高抗封锁能力和节点可用性。
Sing-box 是否兼容 Clash 配置文件？
部分兼容。Sing-box 支持从 Clash 订阅转换工具导入节点，但配置语法略有不同。建议使用第三方订阅转换器，如 sub-converter，将 Clash 格式转换为 Sing-box JSON 格式使用。
Hiddify Next 用户流量配额如何设置？
管理员可为每个用户设置带宽和流量上限，超出限制时可降速或阻止访问。确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性和使用效率。
Quantumult X 的主要功能是什么？
Quantumult X 是一款功能极其强大的 iOS 网络代理应用，支持多种协议和脚本扩展。它可以通过规则分流、广告屏蔽、请求重写等方式优化网络体验。Quantumult X 常被技术用户用于高级自动化与自定义代理策略。
Mihomo 是什么？
Mihomo 是 Clash Premium 的开源替代项目，兼容原版 Clash 配置文件并扩展了部分新功能。它性能优异、内存占用低，适用于希望自定义构建代理环境的高级用户。
